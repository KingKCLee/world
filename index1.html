📋 테스트 방법

  1. F12 키를 눌러 개발자 도구 열기
    이 페이지는 F12 사용 가능합니다 (보안 차단 없음)
  2. Console 탭 선택
    실시간 로그 확인용
  3. Network 탭도 같이 열기
    필터에 "google" 입력
  4. 위의 전화번호 버튼 클릭
    전화 걸기 팝업 뜨면 "취소" 해도 됨
  5. Console 로그에서 "전환 이벤트 발송 완료" 확인
  6. Network 탭에서 google 요청 확인
    googleads.g.doubleclick.net 또는 google.com/pagead 요청이 보여야 함
  7. 15~30분 후 Google Ads → 목표 → 전환 확인
    "viphome 전화 클릭" 전환 수 증가 확인
